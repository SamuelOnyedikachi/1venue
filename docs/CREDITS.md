# Credits

## Hero collage portraits

The faces in the homepage hero collage are photographs of real people, used under the
[Unsplash License](https://unsplash.com/license) (free to use, including commercially;
attribution is appreciated). They are stored as compressed WebP under `public/img/hero/`.
Replicate was not available on the build machine, so licensed Unsplash portraits were used
instead of generated faces.

| File | Source image | Notes |
| --- | --- | --- |
| `public/img/hero/speaker.webp` | [images.unsplash.com/photo-1531123897727-8f129e1688ce](https://images.unsplash.com/photo-1531123897727-8f129e1688ce) | Often credited to Prince Akachi on Unsplash. Photographer name was not re-verified this build because unsplash.com is bot-walled. |
| `public/img/hero/avatar.webp` | [images.unsplash.com/photo-1543610892-0b1f7e6d8ac1](https://images.unsplash.com/photo-1543610892-0b1f7e6d8ac1) | Unsplash portrait used under the Unsplash License. Photographer name was not independently verified this build. |

To confirm a photographer, open the photo page on unsplash.com from the image id above.

Seed avatars and event covers elsewhere in the app are also hot-linked from Unsplash;
see `src/features/seed/fixtures.js`.
